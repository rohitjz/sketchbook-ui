# Sketchbook UI has moved

Sketchbook UI is now the **sketchbook medium of [Analog UI](https://github.com/rohitjz/skills/tree/main/skills/design/analog-ui)**,
which adds seven more mediums (blueprint, museum, lab notebook, risograph zine, receipt, field journal,
departure board) and the method behind them.

```bash
git clone https://github.com/rohitjz/skills && cd skills
./install.sh analog-ui          # then: /analog-ui sketchbook
```
